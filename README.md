# comp115_project1
Magnemite in front of mountains in a desert
There is an internal function to call just the magnemite, can be used elsewhere. 

# Description
This Python program uses the `turtle` graphics library to draw Magnemite, a Pokémon, against a simple desert background. The drawing is created using geometric shapes, lines, circles, and different colours.

# Features
- Custom model and landscape background.
- Magnemite's body, magnets, eye, and screws drawn using Turtle graphics.
- Uses functions and loops to simplify repeated drawing tasks.

# How to run
- easiest way to run is to simply copy and paste code into your favorite python interpreter, then press run
